## 남은 공유 전 확인 사항

1. **공급처 재확인** · F4에서 Enter로 관리에 들어갈 때와 돌아올 때 선택한 공급처만 확인한다. 실제 WSL 환경에서 설치본 `.26`의 전체 조회는 7.4초, Kilo 단독 조회는 0.9초였다. Kilo 무료 경로 14개와 OpenCode 무료 경로 10개가 표시됐다. 자동 실행 게이트웨이에서는 F4를 다시 확인할 때 공급처별 조회가 끝나는 대로 행을 갱신한다. 한 행이 늦거나 실패해도 끝난 행은 그대로 보인다. [공급처 화면](../../cli/tui/provider_status.go)
2. **작업별 모델 비교 범위** · 코딩·추론 비교는 확인된 네 모델 버전에 적용된다. 비교 자료가 없는 모델은 종합 순서의 위치를 유지한다. 실제 무료 경로의 추론 설정과 성능은 벤치마크 실행과 다를 수 있다. WSL에서 Kilo 게스트만 사용한 Auto 시험은 Nemotron 3.5 Super VL을 선택했고, 첫 출력까지 1.8초가 걸렸다. 같은 Nemotron 모델 그룹을 선택한 별도 실사용 시험에서 Kilo는 1.6초, OpenCode는 4.7초 만에 첫 출력을 보냈다. 양쪽 모두 인위적인 확인 문장으로 응답을 완료했다. [현재 모델 우선순위](../../backend/internal/router/model_quality.go), [Artificial Analysis 평가 방법](https://artificialanalysis.ai/evaluations/terminalbench-4-0)
3. **이미지와 MCP** · 브라우저 승인, 만료 후 갱신, 공유 토큰 정리와 채팅에서 모델이 고른 도구의 승인·호출을 격리 서버에서 확인했다. 실서비스 브라우저 승인·무료 이미지 생성과 실제 모델별 MCP 선택 정확도는 남았다. 일반 서버 저장을 지원하기 전 버전으로 롤백한 뒤 F6에서 공유 OAuth 연결을 해제하면 최신 버전에서 다시 승인이 필요할 수 있다. [이미지 연결](../../cli/cmd/freeway/images.go), [MCP 명령](../../cli/cmd/freeway/mcp.go)
4. **배포 환경** · 실제 Windows에서 공백이 포함된 경로의 설치, 잘못된 체크섬 거부, 제거 후 사용자 데이터 보존과 사용자 PATH 실행을 검증했다. Windows에서 DPAPI 인증 저장과 갱신 테스트도 통과했다. Windows ConPTY에서 첫 실행 한국어 선택, 배경색 즉시 미리보기, Esc 복귀와 재실행 후 설정 유지, 한글 문자열 입력을 확인했다. 한국어 화면에서 질문 편집을 취소하고 첨부한 뒤, 내보낸 파일에 한글 질문과 첨부 본문이 들어 있는지 확인했다. Windows Terminal에서 IME로 한글을 조합하는 과정, 브라우저 창과 시스템 클립보드는 별도 확인이 필요하다.
5. **공급처 이미지 출력** · 검토 시점의 OpenRouter와 Gemini 이미지 출력은 유료다. NVIDIA 호스팅 경로는 내부 평가용 약관을 적용한다. Cloudflare Workers AI는 Workers Free 계정의 일일 무료 한도에서 이미지 생성 모델을 제공한다. 연결한 계정의 Workers 플랜과 한도 처리를 검증한 후 공급처 경로로 검토할 수 있다.
