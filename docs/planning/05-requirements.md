# Freeway 요구사항과 완료 조건

## 요구사항의 적용 범위

이 문서의 요구사항은 초기 개인용 로컬 제품에 대한 제안이다. 현재 코드가 이미 충족하는 항목도 회귀 방지를 위해 포함한다. P0는 첫 사용 가능한 버전에 필요한 조건, P1은 신뢰성과 편의 개선, P2는 실제 수요가 생긴 후의 확장이다.

대표 검증 대상은 OpenCode의 무료 DeepSeek 경로와, 다른 서비스에서 제공하는 무료 모델 경로의 통합이다. 모델 이름만 목록에 나타나거나 한 번의 텍스트 응답만 성공한 상태를 코딩 호환성 완료로 인정하지 않는다.

## 무료 정책의 정의

초기 기본 정책은 `strict-free`로 제안한다. 가격·권한·기간·추가 기능 비용을 확인할 수 있는 경로만 자동 선택한다. 일회성 체험 크레딧과 보상으로 받은 잔액은 `credit-funded`로 분리하며 별도 동의 없이 같은 무료 풀에 섞지 않는다.

공식 잔여량 조회가 없는 무료 경로도 존재한다. 이때 비용 조건이 확인됐다면 남은 양은 `unknown`인 채로 이용할 수 있지만, 유료 전환을 막을 수 없거나 전체 비용을 확인할 수 없다면 strict-free 후보에서 제외한다. `unknown remaining`과 `unknown price`는 다른 상태다.

## 완료 조건

첫 사용 가능한 버전은 다음을 모두 충족해야 한다.

1. 사용자의 대표 요구에 해당하는 무료 DeepSeek 경로를 실제로 연결한다.
2. 독립된 다른 무료 경로를 최소 하나 추가하고, 그 경로의 무료 근거와 인터페이스를 기록한다.
3. 추론 API에 노출한 경로는 API 계약 시험을 통과한다. 작업 위임 경로는 별도 목록으로 표시한다.
4. 실패 전 대체, 스트림 후 중단, 인증 만료, 한도 예약 경쟁, 취소를 재현 시험으로 증명한다.
5. 유료 후보와 숨은 보조 호출을 기본 정책이 막는지 검증한다.
6. 설치·연결·모델 선택·실패 원인·사용량을 CLI에서 확인할 수 있다.
7. 문서의 지원 목록과 실제 노출 모델이 일치한다.

## 요구사항을 줄여야 하는 경우

OpenCode나 Cline 경로가 텍스트만 안정적으로 제공하면 그 경로는 `cli-text`까지만 지원한다. 도구 호출을 지원하는 것처럼 꾸며 MVP 조건을 통과시키지 않는다. 특정 API가 모든 경로에서 불가능하면 제품의 추론 API 범위를 줄이고 작업 위임을 독립 기능으로 출시한다. 해당 결정은 [설계 결정](12-decisions-and-questions.md)에 남긴다.
