# CLI와 터미널 사용자 흐름

## 화면이 해결할 문제

사용자는 공급처의 기술적 종류보다 지금 사용할 모델, 무료 조건, 연결해야 하는 계정, 다음 행동을 알고 싶어 한다. 모델 이름만 나열하지 않고 상태와 실제 선택 경로를 함께 보여 준다. 기존 TUI의 대화·모델 선택 경험은 유지하고 상태 표현부터 개선한다.

아래 명령 중 `models`, `connect opencode`, `priority`, `agent`, `status`, `serve` 등은 기존 기능과 연결되는 영역이다. `routes`, `route explain`, `usage`, `probe` 등은 제안 명령이며 현재 구현된 것으로 안내하지 않는다.

## 명령 구조 제안

```text
freeway
freeway models
freeway models --json
freeway routes
freeway connect <provider>
freeway disconnect <provider>
freeway priority
freeway route explain --model <model>
freeway usage
freeway probe <route>
freeway agent --json <prompt>
freeway status
freeway serve
```

`route explain`과 `status`는 추론을 하지 않는다. `probe`는 실제 요청을 보내므로 실행 대상과 사용 가능량 소비를 표시한다. 자동 진단이 유료 모델이나 보조 LLM을 호출하지 않는다.

## 첫 실행

1. 로컬 게이트웨이가 실행 중인지 확인한다.
2. 현재 연결된 경로와 미연결 경로를 구분한다.
3. 사용자에게 현재 준비된 무료 모델을 보여 준다.
4. 원하는 모델이 없으면 제공 가능성이 있는 경로와 연결 방법을 안내한다.
5. 모델 또는 Auto를 선택해 첫 요청을 보낸다.

모든 공급처에 먼저 가입하도록 강요하지 않는다. 대표 경로 하나를 연결하고 실제 응답을 확인한 후 다른 경로를 추가할 수 있어야 한다.

## 모델 선택 화면

```text
DeepSeek V4.1 Flash
  OpenCode   공식 서버 연결됨   무료 할당 소진
  Cline      로그인 완료        모델 거절 · CLI는 프로모션 종료 안내
  OpenRouter 유료               무료 정책에서 제외

무료 자동 선택
  OpenRouter Cohere 응답 성공   요청 비용 0 USD
```

표시는 2026년 11월 16일 실제 호출 결과를 예시로 사용한다. 실제 제품에서는 각 경로의 최신 상태로 갱신한다. 모델 목록과 현재 사용 가능 상태를 구분한다.

## 상태 표현

| 상태 | 보여 줄 내용 | 다음 행동 |
| --- | --- | --- |
| ready | 사용 가능한 경로와 비용 근거 | 선택 또는 요청 |
| needs auth | 공급처 연결이 필요함 | 연결 실행 |
| auth expired | 로그인 만료 | 재로그인 |
| quota exhausted | 한도 범위와 알려진 리셋 | 대기 또는 다른 경로 |
| cooldown | 일시 제한과 재시도 가능 시점 | 다른 경로 또는 대기 |
| unavailable | 최근 오류와 관측 시점 | 상태 갱신 |
| unsupported | 요청 기능을 지원하지 않음 | 기능이 맞는 모델 선택 |
| unverified | 무료 또는 기능 근거 부족 | probe 또는 수동 검증 |
| paid | 0원이 아닌 가격 | 무료 정책에서 제외 |

색상만으로 상태를 구분하지 않는다. 텍스트와 상태 코드를 함께 출력하고, 일반 터미널에서는 ANSI 없이도 의미가 유지되어야 한다.

## 자동 전환 표시

자동 전환은 응답 영역을 진행 로그로 채우지 않고 한 줄 상태로 설명한다.

```text
OpenCode 무료 한도에 도달했습니다. 허용된 다른 무료 모델 경로를 확인합니다.
선택: Requesty · Muse Glimmer 30B · 모델 변경 허용 정책
```

위 예시는 모델 변경을 허용한 Auto 정책에만 적용한다. DeepSeek 고정 요청이라면 Muse로 넘어가지 않고 같은 DeepSeek 경로를 찾거나 오류로 끝낸다. 모델 변경은 사용자 기대와 품질에 영향을 주므로 결과에도 실제 모델을 남긴다.

## 한도 표시

```text
Requesty
  공식 무료 상한: 일 200 요청
  이 Freeway의 오늘 사용: 12 요청
  공급처 확정 잔여량: 조회되지 않음
  진행 중 예약: 1 요청
```

공식 API로 188회가 남았다고 확인한 것이 아니라면 `188회 남음`으로 표시하지 않는다. 다른 도구에서 사용한 양을 놓칠 수 있기 때문이다. 추정값을 표시하면 그 옆에 추정임을 붙인다.

## 비용 표시

주 모델 비용과 전체 실행 비용을 구분한다. 모델 단가뿐 아니라 보조 호출을 포함한 실행 비용이 0이라는 근거가 있어야 전체 무료 성공으로 표시한다. strict-free에서 보조 유료 호출이 필요한 경로는 실행 전에 제외한다.

원래 서비스의 CLI를 직접 실행한 결과가 예상과 달랐다면 주 모델·보조 모델·전체 사용량의 근거를 보여 준다. 사용자에게 무료였다고 먼저 단정한 뒤 작은 비용을 숨기지 않는다.

## 오류 예시

```text
이 요청은 도구 호출을 포함하지만 선택한 OpenCode 경로는 텍스트 브리지입니다.
도구 호출이 검증된 경로를 선택하거나 텍스트 작업 위임으로 실행하세요.
```

```text
Cline 로그인이 만료됐습니다.
공식 로그인으로 다시 연결한 뒤 같은 작업을 재시도할 수 있습니다.
```

오류 안내에 키 전체나 개인 계정 정보를 넣지 않는다. 인증 오류를 한도 부족이라고 설명하지 않는다. 사용자가 이미 연결을 허용했다면 routine한 재조회 때마다 확인을 반복하지 않는다.

## 대화와 취소

취소 키는 현재 요청과 브리지까지 전달되어야 한다. 일부 출력이 있으면 그 상태를 보존하고 중단됨으로 표시한다. 재생성은 새 요청이며 새 한도를 소비할 수 있다. 다른 모델로 재생성했다면 표시한다.

이력 목록에는 생성 시각, 제목, 마지막 모델, 중단 여부를 표시한다. 기본 제목 생성은 프롬프트 일부를 이용하고 별도 유료 요약 모델을 호출하지 않는다. 사용자가 직접 제목을 바꿀 수 있으면 더 좋지만 초기 필수 조건은 아니다.

## TUI와 헤드리스의 일관성

TUI의 모델 선택과 헤드리스 `--model`은 같은 정책과 기능 검사를 사용한다. JSON 모드에서는 진단 문구가 stdout에 섞이지 않는다. UI만 알고 있는 공급처별 우회 로직을 만들지 않는다.

첫 TUI 개선 범위는 상태, 경로 상세, 비용 확인 수준, 선택 이유다. 애니메이션·테마 시스템·새 디자인 시스템·Rust 전면 재작성은 대표 무료 경로가 검증된 뒤 별도로 판단한다.
