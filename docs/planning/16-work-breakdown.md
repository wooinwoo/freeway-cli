# 계층별 작업 분해와 담당 인계

이 문서는 바로 티켓으로 나눌 수 있는 작업 목록이다. 12개 대분류, 24개 중분류, 72개 소분류 태스크로 구성한다. A와 B는 기능별 책임 제안이며 각 태스크에는 작성 책임자 한 명과 상대 검토자를 둔다. 모든 태스크는 계획 상태이며 구현 완료를 뜻하지 않는다.

## 태스크를 사용하는 규칙

소분류 ID를 이슈·브랜치·PR에서 연결한다. 완료는 코드 작성이 아니라 산출물과 수용 기준을 충족한 상태다. 선행 작업의 계약이 바뀌면 영향을 받는 태스크와 fixture도 같이 갱신한다. 조건부 태스크는 해당 인터페이스의 검증 결과가 있을 때만 활성화하며 첫 출시의 필수 게이트에 몰래 추가하지 않는다.

A는 공급처 연결·어댑터·CLI·사용자 docs·패키징·설치를 담당하고, B는 공통 계약·라우팅·한도·API·비밀 저장·데이터 이전·CI·릴리스를 담당한다. 공동 검토가 필요해도 작성 책임자는 표에 적힌 한 명이다. 계정 로그인·실제 무료 사용 권한이 필요한 태스크는 그 선행 조건을 충족하기 전 성공으로 처리하지 않는다.
