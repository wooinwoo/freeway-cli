# 설계 결정과 미결정 사항

## 결정 기록의 사용법

각 결정은 배경, 선택, 대안, 변경 조건을 가진다. 이 초안의 제품 가정은 팀 회의에서 변경할 수 있다. 구현 완료를 뜻하는 결정과 설계 제안을 혼동하지 않는다.

## ADR 001 제품 범위

배경: OpenRouter 내부 기능만 확인하면 외부 서비스의 무료 DeepSeek·Muse 경로를 놓친다.

선택: 무료 권한과 실행 경로를 관리하는 로컬 도구를 제품 범위로 잡는다. OpenRouter는 비교 대상이자 공급 경로 하나다.

대안: OpenRouter의 CLI 래퍼만 만든다.

변경 조건: 사용자의 대표 무료 요구가 기존 OpenRouter·BYOK·클라이언트 조합으로 모두 충족되면 자체 범위를 축소한다.

## ADR 002 실행 계약 분리

배경: 공식 CLI가 JSON을 출력해도 일반 추론 API의 도구 호출 계약을 충족하는 것은 아니다.

선택: 직접 추론, CLI 텍스트, 에이전트 작업을 구분한다. 검증 전에는 CLI 경로를 코딩용 호환 API 후보에 섞지 않는다.

대안: 모든 외부 호출을 문자열 입력과 문자열 출력으로 통일한다.

변경 조건: 특정 브리지에서 도구 호출과 메시지 이력을 손실 없이 전달하는 계약이 시험으로 확인되면 그 경로를 추론 계약으로 승격할 수 있다.

## ADR 003 무료 비용 정책

배경: Ori에서 무료 답변 모델 외에 유료 Jev 호출이 발생했다.

선택: 기본 라우팅은 별도 LLM 판단 없이 규칙으로 수행한다. 주 모델뿐 아니라 보조 요청·추가 기능·프로모션 조건을 포함해 비용을 판단한다.

대안: 주 모델의 입력·출력 단가만 0이면 무료로 취급한다.

변경 조건: 사용자가 명시적으로 유료 보조 기능을 요청하고 별도 예산을 설정한 경우에만 별도 정책으로 추가한다. 초기 제품의 무료 기본값은 유지한다.

## ADR 004 상태 저장소

배경: 현재 JSON 저장소는 단일 프로세스 POC에 맞춰져 있다.

선택 제안: 게이트웨이를 단일 작성자로 유지하며 원자적 예약·저장·복구를 먼저 검증한다. 다중 작성자나 저장 부하가 실제 요구가 되면 SQLite로 옮긴다.

단일 작성자는 Store 초기화 전 데이터 폴더의 배타 잠금으로 보장한다. 공급처 사용량 스냅샷에는 포함 범위를 기록하고, 이 근거가 없으면 로컬 정산을 추정 상태로 유지한다.

대안: 즉시 서버 DB와 분산 잠금을 도입한다.

변경 조건: 여러 프로세스의 공유 쓰기, 내구성 있는 작업 큐, 파일 저장 비용 중 하나가 필요한 단계에서 전환한다. 전환 시 import·백업·rollback 시험을 포함한다.

## ADR 005 언어 선택

배경: Go 학습과 Rust TUI 선호가 대화에서 나왔다. 현재 POC는 Node다.

선택 제안: 대표 경로와 계약 검증은 기존 Node로 진행한다. Go 코어와 Rust TUI는 팀의 명시적 구현 선택으로 남긴다.

대안: 시작부터 두 언어로 전면 재작성한다.

변경 조건: 배포·유지보수·TUI의 구체적 이익 또는 합의된 학습 목표가 있고, 기존 계약 시험을 유지할 수 있을 때 변경한다.

## ADR 006 스트림 커밋 후 전환

배경: 일부 텍스트나 도구 인자가 전송된 뒤 다른 모델을 붙이면 의미와 부작용이 달라진다.

선택: 초기에는 첫 이벤트 전까지만 자동 대체한다. 이후에는 부분 실패와 새 요청을 구분한다.

대안: 끊긴 응답을 다른 모델로 자동 이어 쓴다.

변경 조건: 클라이언트가 명시적인 재시작 프로토콜과 중복 도구 방지를 지원하는 별도 기능을 구현할 때만 검토한다.

## ADR 007 공급처 채택

배경: 무료 플랜의 존재와 외부 자동화·재노출 가능성은 다르다.

선택: 공식 API 또는 공식 자동화 인터페이스와 사용 조건을 경로별로 검증한다. 명시적인 중계·래퍼 제한이 있는 Freebuff 무료 경로는 기본 구현에서 제외한다.

대안: 기술적으로 호출되면 모두 후보에 넣는다.

변경 조건: 제공처가 해당 연동을 허용하는 공식 인터페이스나 명시적 승인을 제공할 때 재평가한다. 이 결정은 다른 공급처에도 같은 제한이 있다는 뜻은 아니다.

## ADR 008 모델 정체성

배경: 같은 계열의 날짜·Flash·Pro·Spark·Glimmer를 묶으면 사용자에게 다른 모델을 제공할 수 있다.

선택: 정확한 모델과 버전 식별을 우선하며, 모호한 별칭은 자동 병합하지 않는다. Auto 정책만 다른 모델 전환을 허용한다.

대안: 제조사와 표시 이름 일부로 느슨하게 묶는다.

변경 조건: 공식 alias 또는 공급처의 명확한 canonical 매핑이 확인되면 매핑을 추가한다. 원래 경로 ID는 보존한다.

## ADR 009 먼저 다룰 공급처

선택 제안: OpenCode DeepSeek, Cline 무료, Requesty Muse를 대표 경로로 검증한다. Kilo와 OpenRouter는 직접 API 비교 기준이다. 이후 NVIDIA 직접 API와 다른 공식 무료 API를 추가한다.

근거: 사용자가 직접 언급한 모델과 서비스, 추론 API와 CLI 권한의 차이를 모두 검증할 수 있다.

변경 조건: 인증이나 모델 프로모션 종료로 경로가 막히면 같은 요구를 검증할 수 있는 다음 후보를 선정하되, 모델 변형이 바뀌었다는 사실을 기록한다.

## 위험과 확인할 증거

| 위험 | 실제 실패 시나리오 | 대응과 증거 |
| --- | --- | --- |
| 프로모션 종료 | 어제 무료였던 모델이 유료로 바뀜 | 갱신 시각·만료·전송 전 가격 검사 |
| 숨은 보조 비용 | 무료 모델 지정 후 요약·판단 호출 과금 | 전체 usage와 별도 generation 대조 |
| 추론과 작업 혼합 | 도구 요청을 CLI 텍스트로 변환하며 의미 손실 | 계약별 API 분리와 tool fixture |
| 한도 중복 계산 | 두 라우터가 같은 상위 무료 풀을 공유 | quota scope 근거와 관측 |
| 계정 외부 사용 | 다른 도구에서 쓴 양이 반영되지 않음 | 공식 잔여량과 로컬 추정 구분 |
| 인증 만료 | 긴 작업 중 공급처가 재로그인을 요구 | 연결 상태 전이와 재개 규칙 |
| 로컬 비밀 노출 | 자식 프로세스·오류·진단에 키 포함 | 최소 환경·마스킹·fixture 검사 |
| 재작성 비용 | 언어를 바꾸며 기존 기능이 회귀 | 기존 API·CLI 계약을 전환 기준으로 고정 |

## 문서 초안의 완료와 제품의 완료

이 지식창고의 첫 초안은 제품 범위, 공개 구조 분석, 후보 조사, 요구사항, 계층 계약, 단계·분업·시험이 서로 연결되면 완료다. 제품은 각 단계의 실제 구현과 공급처 검증 게이트를 통과해야 완료다. 둘을 같은 상태로 표시하지 않는다.
