## Commands

Use `/model`, `/resume`, `/continue`, `/new`, `/fork`, `/rename`, `/attach`, `/detach`, `/queue`, `/save`, `/export`, `/copy`, `/code`, `/settings`, and `/reconnect`.

Type `/` for suggestions; choose with arrows and complete with Tab. Escape closes an open menu before it can interrupt a response.

## Exit safely

Ctrl+C stops generation. With input present it keeps a recoverable copy before clearing. On empty input, press it twice to exit. `/exit` requests a save before closing.
