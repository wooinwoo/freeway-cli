## Personal local execution

Freeway distributes a personal client. Each user connects their own accounts from their own computer. The project does not operate a shared relay or collect provider credentials.

The operator commits to noncommercial operation without paid software sales, subscriptions, or API relay services. This operating policy is separate from the MIT license and does not alter provider terms.

## Data boundaries

Messages and selected file contents reach the connected gateway and chosen upstream service. A local client does not imply local model inference or no upstream retention.

Explicit model selections send requests to that model's provider. When you choose Auto, the gateway may retry with another free provider before output begins.

The TUI uses gateway storage APIs for conversations and drafts. The standalone provider utility can store encrypted keys in its dedicated user directory; a backend may supply its own credential store. The encryption keys for gateway data and provider keys live in the same user directories, so anyone who can read those directories can decrypt them; owner-only directory permissions are the real protection boundary. Image MCP sign-in data additionally uses operating-system user protection (DPAPI) on Windows only.

## Free conditions

Zero token pricing is not unlimited allowance. Plan, model, region, promotion, training consent, and evaluation-only terms affect eligibility. Review the selected provider's current data policy before sending personal or confidential information.

## Secrets and exports

Keep provider and local gateway keys out of command arguments, source control, screenshots, and reports. Markdown exports are plaintext, even when the original is stored encrypted.

## Independent compatibility

Provider names identify connected services. They do not imply partnership, endorsement, or approval of every use. Software licenses and hosted service terms are separate.
