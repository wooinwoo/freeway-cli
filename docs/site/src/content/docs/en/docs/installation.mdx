Freeway packages contain `freeway`, `freeway-providers`, a file manifest, and license notices. Choose the archive matching your operating system and CPU. Keep both executables together.

<Aside title="Release availability">
Release publication is separate from this checkout. These instructions also work with archives produced locally. If no release is published, build the package from source; do not download an archive from an unrelated mirror.
</Aside>

## Installer scripts

The repository root includes `install.sh` and `install.ps1`. Source installation is available now with Go 1.26+:

<Tabs>
<TabItem label="Linux / macOS">

~~~sh
bash install.sh --source
export PATH="$HOME/.freeway/app/bin:$PATH"
~~~

</TabItem>
<TabItem label="Windows">

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Source
$env:Path = "$HOME\.freeway\app\bin;$env:Path"
~~~

</TabItem>
</Tabs>

Run from a source checkout. The script builds the current OS/CPU package, verifies it, and delegates activation to the native installer. Node.js is not used. `--root PATH` or `-Root PATH` chooses a dedicated install directory. PATH changes above apply to the current terminal; add the same directory to your shell configuration or Windows user PATH for future terminals.

### Install a local archive

No manual extraction is needed:

~~~sh
bash install.sh --archive ./freeway_VERSION_linux_amd64.tar.gz --sha256 EXPECTED_SHA256
~~~

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Archive .\freeway_VERSION_windows_amd64.zip -SHA256 EXPECTED_SHA256
~~~

Use a checksum from a trusted source. The archive is checked before its executable runs.

### Download a native release

Once the new native release assets are published, run `bash install.sh` or `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1` without source/archive flags. This detects the OS and CPU, fetches `SHA256SUMS` and the matching archive, verifies SHA256, and installs without Go or Node.js. A missing release fails without changing the installed version. `--release-url HTTPS_BASE_URL` / `-ReleaseUrl HTTPS_BASE_URL` selects a trusted release directory.

## Build release archives

Install Go 1.26 or later. From the repository root:

~~~sh
go -C cli run ./cmd/package --root "$PWD"
~~~

This creates archives for Linux, macOS, and Windows on amd64 and arm64 in `dist/native`, plus `SHA256SUMS` and `release.json`. To build one target, append `--targets linux/amd64`. Cross compilation does not prove execution on another operating system.

## Verify and install

Get the expected SHA256 from the trusted release's `SHA256SUMS`. A matching hash detects a damaged or substituted archive when the expected hash comes from a trusted source.

<Tabs>
<TabItem label="macOS / Linux">

~~~sh
# Use the actual version and architecture in the filename.
sha256sum freeway_VERSION_linux_amd64.tar.gz
# On macOS: shasum -a 256 freeway_VERSION_darwin_arm64.tar.gz
mkdir freeway-package
tar -xzf freeway_VERSION_linux_amd64.tar.gz -C freeway-package
./freeway-package/freeway install \
  --archive ./freeway_VERSION_linux_amd64.tar.gz \
  --sha256 EXPECTED_SHA256
~~~

Add `$HOME/.freeway/app/bin` to your shell's PATH, then open a new terminal.

</TabItem>
<TabItem label="Windows">

~~~powershell
Get-FileHash .\freeway_VERSION_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\freeway_VERSION_windows_amd64.zip .\freeway-package
.\freeway-package\freeway.exe install --archive .\freeway_VERSION_windows_amd64.zip --sha256 EXPECTED_SHA256
~~~

Add `$HOME\.freeway\app\bin` to your user PATH, then open a new terminal. Windows may ask for permission to run an unsigned application. No administrator installation is required.

</TabItem>
</Tabs>

Replace `VERSION` and `EXPECTED_SHA256` with the actual filename and checksum. Verify the archive before running the extracted executable. `--root PATH` selects a dedicated application directory; add its `bin` directory to PATH.

## Check the installation

~~~sh
freeway --version
freeway
~~~

Freeway starts the bundled gateway and opens the chat. Use `freeway --preview` when you want to explore the interface offline. [Gateway options](./gateway/)

## Installation layout

~~~text
~/.freeway/app/
  bin/freeway                 stable launcher (freeway.exe on Windows)
  install.json                active and previous versions
  versions/VERSION/
    freeway
    freeway-providers
    manifest.json
    LICENSE
    THIRD_PARTY_NOTICES.md
    licenses/
~~~

Provider accounts and gateway conversations live outside the managed application directory. Do not store personal files inside `versions`.
