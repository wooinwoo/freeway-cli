## Install on Windows

Download **Freeway-Setup-x64.exe** for most Windows PCs or **Freeway-Setup-arm64.exe** for Windows on Arm from the official [GitHub Releases](https://github.com/wooinwoo/freeway-cli/releases).

1. Double-click the setup file and confirm installation.
2. Open Freeway from the finish dialog. Search for **Freeway** in the Start menu to open it again.

The setup file includes the full package. It installs under `$HOME\.freeway\app` and needs no administrator access, Go, Node.js, or PATH changes. Windows may show an unsigned-app prompt.

Freeway packages contain `freeway`, `freewayd`, `freeway-providers`, a file manifest, and license notices. Choose the archive matching your operating system and CPU and keep the three executables together. The local gateway runs in `freewayd`.

## Install on Linux and macOS

Download the installer script and run it without options. It detects the OS and CPU, fetches `SHA256SUMS` and the matching archive from the latest release, verifies SHA256, and installs without Go or Node.js. It needs `curl`, `tar`, and `sha256sum` or `shasum`.

~~~sh
curl -fsSLO https://raw.githubusercontent.com/wooinwoo/freeway-cli/main/install.sh
bash install.sh
export PATH="$HOME/.freeway/app/bin:$PATH"
~~~

To use a script on Windows, download `install.ps1` the same way and run `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`. If the release cannot be fetched, the script fails without changing the installed version. `--release-url HTTPS_BASE_URL` / `-ReleaseUrl HTTPS_BASE_URL` selects a trusted release directory. `--root PATH` or `-Root PATH` chooses a dedicated install directory. PATH changes above apply to the current terminal; add the same directory to your shell configuration or Windows user PATH for future terminals.

<Aside title="Use the official source">
Download releases only from the official GitHub Releases page. Each release contains archives for each OS and CPU, both Windows setup executables, `SHA256SUMS`, `release.json`, and its signature `release.json.sig`. Do not download an archive from an unrelated mirror.
</Aside>

## Install from source

You need Go 1.26+ and a repository checkout.

<Tabs>
<TabItem label="Linux / macOS">

~~~sh
bash install.sh --source
export PATH="$HOME/.freeway/app/bin:$PATH"
~~~

</TabItem>
<TabItem label="Windows">

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Source
$env:Path = "$HOME\.freeway\app\bin;$env:Path"
~~~

</TabItem>
</Tabs>

The script builds the current OS/CPU package, verifies it, and delegates activation to the native installer. Node.js is not used.

## Install a local archive

No manual extraction is needed:

~~~sh
bash install.sh --archive ./freeway_VERSION_linux_amd64.tar.gz --sha256 EXPECTED_SHA256
~~~

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Archive .\freeway_VERSION_windows_amd64.zip -SHA256 EXPECTED_SHA256
~~~

Use a checksum from a trusted source. The archive is checked before its executable runs.

## Build release archives

Install Go 1.26 or later. From the repository root:

~~~sh
go -C cli run ./cmd/package --root "$PWD"
~~~

This creates archives for Linux, macOS, and Windows on amd64 and arm64, both Windows Setup executables, `SHA256SUMS`, and `release.json` in `dist/native`. To build one target, append `--targets linux/amd64`. Build and execution verification are separate stages.

## Verify and install

Get the expected SHA256 from the trusted release's `SHA256SUMS`. A matching hash detects a damaged or substituted archive when the expected hash comes from a trusted source.

<Tabs>
<TabItem label="macOS / Linux">

~~~sh
# Use the actual version and architecture in the filename.
sha256sum freeway_VERSION_linux_amd64.tar.gz
# On macOS: shasum -a 256 freeway_VERSION_darwin_arm64.tar.gz
mkdir freeway-package
tar -xzf freeway_VERSION_linux_amd64.tar.gz -C freeway-package
./freeway-package/freeway install \
  --archive ./freeway_VERSION_linux_amd64.tar.gz \
  --sha256 EXPECTED_SHA256
~~~

Add `$HOME/.freeway/app/bin` to your shell's PATH, then open a new terminal.

</TabItem>
<TabItem label="Windows">

~~~powershell
Get-FileHash .\freeway_VERSION_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\freeway_VERSION_windows_amd64.zip .\freeway-package
.\freeway-package\freeway.exe install --archive .\freeway_VERSION_windows_amd64.zip --sha256 EXPECTED_SHA256
~~~

Add `$HOME\.freeway\app\bin` to your user PATH, then open a new terminal. Windows may ask for permission to run an unsigned application. No administrator installation is required.

</TabItem>
</Tabs>

Replace `VERSION` and `EXPECTED_SHA256` with the actual filename and checksum. Verify the archive before running the extracted executable. `--root PATH` selects a dedicated application directory; add its `bin` directory to PATH.

## Check the installation

~~~sh
freeway --version
freeway
~~~

Freeway starts the bundled gateway and opens the chat. Use `freeway --preview` when you want to explore the interface offline. [Gateway options](./gateway/)

## Installation layout

~~~text
~/.freeway/app/
  bin/freeway                 stable launcher (freeway.exe on Windows)
  install.json                active and previous versions
  versions/VERSION/
    freeway
    freewayd
    freeway-providers
    manifest.json
    LICENSE
    THIRD_PARTY_NOTICES.md
    licenses/
~~~

Provider accounts and gateway conversations live outside the managed application directory. Do not store personal files inside `versions`.
