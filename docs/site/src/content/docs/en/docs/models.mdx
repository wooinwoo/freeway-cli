## Select a model

Open `/model`, **F2**, or **Alt+P**. Search, select, and continue writing. Closing the menu preserves your draft.

The picker shows free, ready models. When multiple providers offer the same model, the picker lists them together on one row. Responses identify the model and provider used.

Press **Ctrl+T** to cycle through General, Coding, and Reasoning. Coding uses Terminal-Bench 4.0 and Reasoning uses HLE-Diamond. Models with comparable results are reordered among their existing positions. The source comparisons were checked on 2026-11-20. Reasoning settings and results on a free route can differ from the published evaluations. [Terminal-Bench 4.0](https://artificialanalysis.ai/evaluations/terminalbench-4-0) · [HLE-Diamond](https://artificialanalysis.ai/evaluations/hle-diamond)

**Auto** uses the matching comparison when it detects a clear request to implement a function, fix code, or prove a statement. Manual model choices and explicit routing preferences retain priority.

You can change the model or response length while a reply is in progress. The new choice takes effect on the next question.

If every route for the selected model disappears from the catalog, Freeway keeps your selection and draft. Open **F2** and press **Ctrl+R** to check for restored routes before sending. Use `/queue resume` to continue paused follow-ups.

## Write and stream

**Enter** sends. **Ctrl+J**, **Ctrl+O**, **Alt+Enter**, or **Shift+Enter** inserts a newline. Input grows up to six visible lines.

During generation, write a follow-up and press **Tab** or **Enter** to queue it. Use `/queue pause`, `resume`, or `clear`. Restored queues start paused.

## Stop and retry

The composer shows an estimated reply length when the current prompt and conversation approach the local token allowance. Press **F5** to retry once when the gateway offers a shorter reply. Use `/settings` to change the default length.

**Esc** stops the response while keeping your next draft. **Alt+R** regenerates the last question. Regeneration is disabled during session loading.

## Review what will be sent

Press **F8** or run `/context` to review the earlier questions and attachments included with the next draft. Press Enter on the earlier-turns row to cycle through all turns, the last eight, the last three, and the current question only. Use a command such as `/context last 2` for a custom count.

Select a file in **F8** and press Enter to exclude or include earlier copies of that path. **Clear file exclusions** restores all individual choices. Use the earlier-attachments row or `/context attachments off` to turn off all earlier files while keeping those choices.

Files attached to the current question stay in the request. Alt+R and F5 include the attachments of the question being retried. Freeway saves the settings per conversation and keeps the original messages and attachments in history.

If a provider is rate-limited or unavailable before output starts, the gateway can try another provider of the same selected model. Once output starts, the client preserves the partial response and reports the error. Failed and stopped assistant messages are excluded from later model context.

## Understand usage

Unknown usage is not a confirmed zero. The provider quota view reports configuration and observed errors, not guaranteed remaining allowance. Other applications can share that allowance, and free promotions can end.
