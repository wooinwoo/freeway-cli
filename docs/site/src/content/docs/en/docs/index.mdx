Freeway is a personal, native Go terminal client for model APIs and official CLIs. Use your own accounts and keep conversations, drafts, and file context together.

## Install the native client

The repository now includes `install.sh` and `install.ps1`. The new native release assets are not published yet, so use **source installation with Go 1.26+** today. Node.js is not required.

<Tabs>
<TabItem label="Linux">

~~~sh
git clone https://github.com/wooinwoo/freeway-cli.git
cd freeway-cli
bash install.sh --source
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="macOS">

~~~sh
git clone https://github.com/wooinwoo/freeway-cli.git
cd freeway-cli
bash install.sh --source
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="Windows">

~~~powershell
git clone https://github.com/wooinwoo/freeway-cli.git
cd freeway-cli
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Source
$env:Path = "$HOME\.freeway\app\bin;$env:Path"
freeway --preview
~~~

</TabItem>
</Tabs>

The script builds only your platform, verifies the archive, and activates both native executables. See [installation](./installation) for local archives, release downloads, and a custom directory. Preview is offline and needs no credentials.

## Explore Freeway

Start with the part of Freeway you need. Everything runs on your own computer, using your own accounts.

| Start with | Use it for |
| --- | --- |
| [Terminal workspace](./sessions) | Conversations, drafts, and file context. Offline preview is available; connected chat needs the unfinished local gateway. |
| [Provider tools](./connections) | Connect an account, browse models, and make direct model requests. |
| [Native packages](./installation) | Install verified executables, update, and roll back without Node.js. |

## Connect a provider

~~~sh
freeway providers auth kilo
freeway providers models kilo
~~~

Start with the current model list. [Provider connections](./connections) explains API keys, official login, free-account confirmation, and service conditions.

## Open a conversation

<Aside title="A local gateway is required">
Connected conversations use authenticated local Go gateway API v1. The common gateway is not implemented in this checkout; it is scheduled for the final backend phase. Today you can use the offline preview and direct provider commands. The client never silently starts the historical POC or substitutes sample responses.
</Aside>

Set the address and client key issued by your local gateway:

~~~sh
export FREEWAY_URL=http://127.0.0.1:4141
export FREEWAY_API_KEY=your-local-gateway-client-key
freeway
~~~

In PowerShell, use `$env:FREEWAY_URL` and `$env:FREEWAY_API_KEY`. This is the local gateway key, not a vendor API key. Keep it out of issues and screenshots.

Choose `/model`, write a question, and press **Enter**. **Esc** stops the response while keeping your next draft.

## Continue your work

~~~sh
freeway continue
freeway resume
freeway sessions
~~~

Saved sessions are scoped to the current project. See [sessions and drafts](./sessions) for attachments, forks, and recovery.
