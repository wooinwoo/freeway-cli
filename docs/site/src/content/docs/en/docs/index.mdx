Freeway is a personal, native Go terminal client for model APIs and official CLIs. Use your own accounts and keep conversations, drafts, and file context together.

## Install the native client

Install the native package from the official [GitHub Releases](https://github.com/wooinwoo/freeway-cli/releases). Go and Node.js are not required.

<Tabs>
<TabItem label="Linux / macOS">

~~~sh
curl -fsSLO https://raw.githubusercontent.com/wooinwoo/freeway-cli/main/install.sh
bash install.sh
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="Windows">

Download **Freeway-Setup-x64.exe** (or **Freeway-Setup-arm64.exe** for Windows on Arm) from the release, run it, then open **Freeway** from the Start menu.

</TabItem>
</Tabs>

The script detects your OS and CPU, verifies the latest release checksum, and installs `freeway`, `freewayd`, and `freeway-providers` together. See [installation](./installation) for source builds (Go 1.26+), local archives, and custom install locations. The preview works offline without an account.

## Get a direct provider response

Use the bundled provider tool after installation. These calls go from your computer to Kilo and use the provider's allowance.

~~~sh
freeway providers auth kilo
freeway providers models kilo
freeway providers probe kilo --model MODEL_ID
~~~

Replace `MODEL_ID` with an ID returned by the model list. A successful probe returns `FREEWAY_PROVIDER_OK`. Check [provider connections](./connections/) for keys, CLI login, and free eligibility.

## Connect the terminal workspace

Run `freeway` for connected chat. It starts the included [local gateway](./gateway/) automatically. Run `freeway continue` to reopen the latest conversation in the project.

See [sessions and drafts](./sessions/) for project scope, attachments, and recovery.
