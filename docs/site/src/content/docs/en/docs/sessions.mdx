## Resume your project

~~~sh
freeway continue
freeway resume
freeway resume "Session title"
freeway sessions --all
~~~

Title and ID-prefix searches respect project scope. Use `--all` to include other projects.

Press **Alt+H** to browse saved conversations. Type to search titles, IDs, previews, and project paths across the selected scope. The current gateway loads up to 50 conversations at a time. When more are available, press **End**, then **Enter** to load the next page. Press **Ctrl+A** to switch between this project and all projects, or **Ctrl+R** to refresh the list.

In the composer, **Ctrl+R** opens saved prompt search for this project. Press **Ctrl+A** in the picker to include all projects, then **Enter** to restore a prompt as an editable draft. The picker loads recent saved prompts when you open it.

## Drafts and stash

Drafts, text attachments, queued follow-ups, and the **Ctrl+S** stash belong to saved conversation state. Ctrl+S stashes or restores; with two drafts it swaps them.

Freeway saves conversations and drafts during streaming. Use `/save` to retry a temporary failure. The status line warns when a conversation approaches the 8 MiB save limit.

If a conflict or oversized conversation blocks navigation, press **F6** to save a recovery file and continue. The plaintext JSON in `~/.freeway/recovery` includes the conversation, draft, attachments, pending follow-ups, and stashed draft. If no navigation was requested, F6 saves the file and opens a new conversation.

**F7** or `/restore` brings the draft and attachments from the latest recovery file into the composer. Use `/restore "path"` to choose another file. Press **Ctrl+Z** to restore the previous input.

## Attach text files

Use `@` or `/attach` for UTF-8 files inside the project: up to five files, each at most 128 KB. Submission waits for selected files to load. `/detach` removes them.

File contents reach the selected model. Review confidential material before attaching it.

## Fork and export

`/fork` preserves the original and creates a branch. Editing an earlier question also creates a branch.

`/export filename.md` creates a local Markdown copy without overwriting an existing file. It includes messages, draft attachments, stash, and queued follow-ups. Exports are plaintext.

## Multiple windows

A stale revision receives `chat_conflict`. Export the affected window's work, then reopen the saved conversation. Different edits are not silently merged.
