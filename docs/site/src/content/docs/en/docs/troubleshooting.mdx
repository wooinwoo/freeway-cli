---
title: Troubleshooting
description: Separate local connection, account, and upstream problems.
---
## Cannot reach the gateway

Use `/reconnect` to rediscover the bundled gateway from an open conversation. If you set `FREEWAY_URL` for a custom connection, check its loopback address and `FREEWAY_API_KEY`. Use `freeway --preview` to open the interface offline.

## Login or key required

`FREEWAY_API_KEY` authenticates the local connection. Provider keys authenticate their services. Use official CLI login for OpenCode/Cline. Never paste keys into issues.

If `credential_conflict` appears, another command changed the same provider. Check the current account before confirming it again.

## No free model is ready

Inspect the current model list and `freeway providers quota all`. Setup, catalog presence, and live response success are distinct. A promotion may have ended or an account may have reached its allowance.

## Response stopped or incomplete

Partial answers stay incomplete and are excluded from future model context. Press **Alt+R** to retry the selected model. To send the request to Auto, use `/auto` and then press **Alt+R**.

## Another window changed the conversation

Choose the saved session again and press **F6** to preserve this window's work in a recovery file. Revision conflicts protect the newer stored version.

## Cannot save

Use `/save` to retry a temporary error. If the conversation exceeds the save limit, press **F6** to keep a plaintext recovery file with attachments and drafts. If history marks a conversation as `Conversation needs recovery`, keep its original file and restore it from a backup.

## Report a problem

Include the native version, OS, provider ID, command, and shortest reproduction. Remove keys, private prompts, and personal paths. Use the [GitHub issue tracker](https://github.com/wooinwoo/freeway-cli/issues).
