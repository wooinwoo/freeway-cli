## 프로젝트 대화 이어가기

~~~sh
freeway continue
freeway resume
freeway resume "대화 제목"
freeway sessions --all
~~~

제목·ID 앞부분 검색은 프로젝트 범위를 따릅니다. 다른 프로젝트를 포함하려면 `--all`을 사용합니다.

## 초안과 보관함

초안, 텍스트 첨부, 대기 질문, **Ctrl+S** 보관함은 저장할 대화 상태에 포함됩니다. Ctrl+S로 보관·복원하며 양쪽에 초안이 있으면 서로 바꿉니다.

스트리밍 중에도 별도로 저장합니다. 실패는 화면에 남고 `/save`로 재시도할 수 있습니다. 영속 저장과 비정상 종료 복구는 연결한 게이트웨이의 책임입니다.

## 텍스트 파일 첨부

`@` 또는 `/attach`에서 프로젝트 내부 UTF-8 파일을 선택합니다. 질문당 5개, 파일당 최대 128 KB입니다. 선택한 파일을 읽는 동안 먼저 전송하지 않습니다. `/detach`로 제거합니다.

파일 내용은 선택한 모델에 전달됩니다. 기밀 자료는 첨부 전에 확인하세요.

## 분기와 내보내기

`/fork`는 원본을 보존하며 분기를 만듭니다. 이전 질문을 수정해도 분기를 만듭니다.

`/export filename.md`는 기존 파일을 덮어쓰지 않고 메시지·초안 첨부·보관함·대기 질문을 Markdown으로 저장합니다. 내보낸 파일은 평문입니다.

## 여러 창

예전 revision은 `chat_conflict`로 거절합니다. 해당 창의 작업을 내보낸 뒤 저장 대화를 다시 여세요. 서로 다른 수정을 몰래 합치지 않습니다.
