## 프로젝트 대화 이어가기

~~~sh
freeway continue
freeway resume
freeway resume "대화 제목"
freeway sessions --all
~~~

제목·ID 앞부분 검색은 프로젝트 범위를 따릅니다. 다른 프로젝트를 포함하려면 `--all`을 사용합니다.

**Alt+H**로 저장 대화를 엽니다. 검색어를 입력하면 현재 범위에 있는 대화의 제목, ID, 미리보기, 프로젝트 경로를 검색합니다. 현재 게이트웨이는 한 번에 최대 50건을 불러옵니다. 더 볼 대화가 있으면 **End**를 누른 뒤 **Enter**로 다음 페이지를 불러옵니다. **Ctrl+A**로 현재 프로젝트와 전체 프로젝트를 전환하고, **Ctrl+R**로 목록을 새로고침합니다.

입력창에서 **Ctrl+R**을 누르면 현재 프로젝트의 저장 질문을 검색합니다. 검색창에서 **Ctrl+A**로 전체 프로젝트를 포함할 수 있고, **Enter**로 선택한 질문을 수정 가능한 초안으로 불러옵니다. 최근 저장 질문은 검색창을 열 때 불러옵니다.

## 초안과 보관함

초안, 텍스트 첨부, 대기 질문, **Ctrl+S** 보관함은 저장할 대화 상태에 포함됩니다. Ctrl+S로 보관·복원하며 양쪽에 초안이 있으면 서로 바꿉니다.

스트리밍 중에도 대화와 초안을 저장합니다. 일시적인 저장 오류는 `/save`로 재시도하세요. 저장 한도에 가까워지면 상태 줄에 8 MiB 한도 안내가 표시됩니다.

저장 충돌이나 용량 초과로 전환이 멈췄다면 **F6**으로 복구 파일을 만든 뒤 계속할 수 있습니다. `~/.freeway/recovery` 아래 JSON 파일에 대화, 초안, 첨부, 대기열과 보관한 초안을 평문으로 저장합니다. 전환 요청 없이 F6을 누르면 복구 파일을 저장하고 새 대화를 엽니다.

**F7** 또는 `/restore`는 최신 복구 파일의 초안과 첨부를 입력창에 가져옵니다. 다른 파일은 `/restore "경로"`로 선택할 수 있습니다. 가져오기 전 입력은 **Ctrl+Z**로 되돌릴 수 있습니다.

## 텍스트 파일 첨부

`@` 또는 `/attach`에서 프로젝트 내부 UTF-8 파일을 선택합니다. 질문당 5개, 파일당 최대 128 KB입니다. 선택한 파일을 읽는 동안 먼저 전송하지 않습니다. `/detach`로 제거합니다.

파일 내용은 선택한 모델에 전달됩니다. 기밀 자료는 첨부 전에 확인하세요.

## 분기와 내보내기

`/fork`는 원본을 보존하며 분기를 만듭니다. 이전 질문을 수정해도 분기를 만듭니다.

`/export filename.md`는 기존 파일을 덮어쓰지 않고 메시지·초안 첨부·보관함·대기 질문을 Markdown으로 저장합니다. 내보낸 파일은 평문입니다.

## 여러 창

예전 revision은 `chat_conflict`로 거절합니다. 해당 창의 작업을 내보낸 뒤 저장 대화를 다시 여세요. 서로 다른 수정을 몰래 합치지 않습니다.
