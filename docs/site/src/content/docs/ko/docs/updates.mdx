## 확인과 업데이트

~~~sh
freeway update check
freeway update
~~~

기본 출처는 Freeway GitHub 릴리스 명세입니다. 릴리스가 없거나 접속할 수 없으면 오류를 알리고 현재 설치 버전을 유지합니다. `update check`는 정보만 읽으며 설치하지 않습니다.

릴리스 명세 `release.json`에는 Ed25519 서명 `release.json.sig`가 함께 배포됩니다. 클라이언트는 실행 파일에 내장된 공개키로 서명을 확인한 뒤에만 명세의 압축 파일 주소와 해시를 사용합니다. 서명이 없거나 맞지 않으면 업데이트하지 않고 현재 설치 버전을 유지합니다.

`update`는 새 버전을 적용하고, 설치본에 손상이 있으면 같은 버전도 복구합니다. 설치본이 정상이고 버전이 같으면 압축 파일 다운로드를 생략합니다. 같은 버전의 검증된 로컬 패키지로도 복구할 수 있습니다. 이전 버전을 쓰려면 `rollback` 또는 검증된 로컬 패키지 설치를 사용하세요.

이 기능이 들어오기 전에 설치한 고정 실행기를 갱신하려면 Freeway를 닫고 최신 [설치 스크립트](../installation/)를 다시 실행하세요.

업데이터는 압축 파일 SHA256, 안전한 경로, 운영체제·CPU, API 버전, 필수 파일, 개별 파일 해시와 세 실행 파일(`freeway`, `freeway-providers`, `freewayd`)의 버전 출력을 검사합니다. 새 버전을 별도 폴더에서 준비한 다음 `install.json`의 활성 버전을 바꿉니다. 실행 중인 세션은 기존 실행 파일을 계속 사용합니다.

## 검증된 로컬 패키지 설치

~~~sh
freeway install --archive ./freeway_VERSION_linux_amd64.tar.gz --sha256 EXPECTED_SHA256
~~~

Windows에서는 대상에 맞는 ZIP 파일을 사용합니다. 같은 버전에 다른 내용의 패키지는 덮어쓰지 않습니다. 릴리스 패키지에는 Node.js 실행 환경, 공급처 계정 정보와 대화 데이터베이스를 넣지 않습니다.

## 이전 버전으로 복구

~~~sh
freeway rollback
~~~

이전에 설치한 버전을 검증한 뒤 활성화합니다. 계정 파일이나 대화 데이터베이스는 변경하지 않습니다. 활성 실행 파일이 손상돼도 고정 진입점에서 복구 명령을 실행할 수 있습니다. 이전 버전 자체가 검증을 통과해야 복구할 수 있습니다.

## 프로그램 제거

실행 중인 대화를 닫은 다음 실행합니다.

~~~sh
freeway uninstall
~~~

관리 대상 실행 진입점·버전 폴더·설치 상태만 제거합니다. 공급처 인증 정보와 게이트웨이 데이터는 보존합니다. 더 이상 사용하지 않는 PATH 항목은 직접 지우세요.

Windows에서는 Freeway가 종료된 뒤 임시 도우미가 제거합니다. 다른 Freeway 프로세스도 닫아야 실행 파일을 지울 수 있습니다. 제거를 마치지 못하면 임시 `freeway-uninstall-*` 폴더에 오류 로그가 남습니다. 제거 예약 메시지는 모든 파일의 제거 완료를 뜻하지 않습니다.

## 사용자 지정 설치

`--root PATH`로 프로그램 전용 설치 폴더를 지정합니다. 설치된 진입점은 자신의 설치 위치를 사용합니다. `--release-url HTTPS_URL`은 직접 만든 릴리스 등을 시험하기 위한 출처 설정입니다. 해당 명세와 해시를 관리하는 주체는 실행 코드를 배포할 수 있으므로 신뢰하는 출처만 사용하세요.

## 시작할 때 업데이트 확인

설치된 Freeway를 대화형으로 실행해 내장 게이트웨이에 연결할 때 최신 릴리스를 확인합니다. 새 버전이 있으면 **업데이트 후 시작** 또는 **현재 버전으로 계속**을 고를 수 있으며, 동의하지 않으면 설치하지 않습니다. 확인은 최대 3초 기다리며 실패해도 현재 버전으로 시작합니다. `FREEWAY_URL`·`FREEWAY_API_KEY`로 다른 게이트웨이에 연결하거나 `go run`으로 소스에서 실행할 때는 확인하지 않습니다. 시작할 때 확인을 끄려면 `FREEWAY_NO_UPDATE_CHECK=1`을 설정하세요. `freeway update`는 언제든 직접 실행할 수 있습니다.

공급처 공식 CLI 설치·버전·로그인은 별개이며 공급처 연결 문서에서 안내합니다.
