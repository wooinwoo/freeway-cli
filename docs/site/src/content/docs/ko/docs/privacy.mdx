## 개인용 로컬 실행

Freeway는 개인용 클라이언트를 배포합니다. 사용자가 자신의 PC에서 본인 계정을 연결합니다. 프로젝트가 공용 중계 서비스를 운영하거나 공급처 키를 수집하지 않습니다.

운영자는 유료 판매·구독·API 중계 없이 비상업적으로 운영한다는 방침을 둡니다. 이 방침은 MIT 라이선스와 별개이며 공급처 약관을 바꾸지 않습니다.

## 데이터 경계

메시지와 선택한 파일 내용은 게이트웨이와 선택한 외부 서비스에 전달됩니다. 클라이언트가 로컬이라고 모델도 로컬에서 실행되거나 외부 서비스가 보존하지 않는다는 뜻은 아닙니다.

직접 고른 모델의 요청은 해당 공급처로 보냅니다. Auto를 선택하면 첫 답변이 오기 전에 다른 무료 공급처로 재시도할 수 있습니다.

TUI는 게이트웨이 저장 API로 대화와 초안을 관리합니다. 독립 공급처 도구는 전용 사용자 폴더에 암호화된 키를 저장할 수 있으며 백엔드는 자체 저장소를 주입할 수 있습니다. 게이트웨이 데이터와 공급처 키의 암호화 키도 같은 사용자 폴더에 보관합니다. 그래서 폴더를 읽을 수 있는 사람은 내용을 복호화할 수 있으며, 실제 보호 경계는 소유자만 접근할 수 있는 폴더 권한입니다. 이미지 MCP 로그인 정보는 Windows에서만 운영체제 사용자 보호(DPAPI)를 추가로 적용합니다.

## 무료 사용 조건

단가 0은 무제한 할당량이 아닙니다. 플랜·모델·지역·프로모션·학습 동의·평가 전용 조건을 확인하세요. 개인정보나 기밀을 보내기 전에 공급처의 현재 데이터 정책을 확인하세요.

## 비밀과 내보내기

공급처·로컬 게이트웨이 키를 명령행 인수·소스 관리·화면 캡처·제보에 넣지 마세요. 원본이 암호화되어 있어도 Markdown 내보내기는 평문입니다.

## 독립적인 호환성 표시

공급처 이름은 연결 서비스를 식별하기 위한 것입니다. 제휴·보증이나 모든 용도의 승인을 뜻하지 않습니다. 소프트웨어 라이선스와 호스팅 서비스 약관은 별개입니다.
