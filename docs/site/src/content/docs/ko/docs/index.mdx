Freeway는 개인 PC에서 실행되는 Go 기반 터미널 클라이언트입니다. 본인의 계정으로 모델 API와 공식 CLI를 연결하고 대화·초안·파일 문맥을 함께 관리합니다.

## 네이티브 클라이언트 설치

네이티브 압축 파일을 푼 뒤 **압축을 푼 폴더에서** 실행합니다. 운영체제·CPU에 맞는 파일과 `SHA256SUMS`의 해시를 사용하세요. 압축 해제와 소스 빌드는 [설치 안내](./installation)에 있습니다. 공개 릴리스 배포는 아직 전입니다.

<Tabs>
<TabItem label="Linux">

~~~sh
./freeway install \
  --archive ../freeway_VERSION_linux_amd64.tar.gz \
  --sha256 EXPECTED_SHA256
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="macOS">

~~~sh
./freeway install \
  --archive ../freeway_VERSION_darwin_arm64.tar.gz \
  --sha256 EXPECTED_SHA256
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="Windows">

~~~powershell
.\freeway.exe install `
  --archive ..\freeway_VERSION_windows_amd64.zip `
  --sha256 EXPECTED_SHA256
$env:Path = "$HOME\.freeway\app\bin;$env:Path"
freeway --preview
~~~

</TabItem>
</Tabs>

`VERSION`과 `EXPECTED_SHA256`은 패키지 버전과 신뢰하는 체크섬으로 바꾸세요. Intel Mac이나 arm64 Linux·Windows는 해당 CPU용 파일을 사용합니다. 미리보기는 계정이나 모델 요청 없이 오프라인으로 동작합니다.

## Freeway 둘러보기

필요한 기능부터 시작하세요. 모든 도구는 자신의 컴퓨터에서 본인의 계정으로 실행합니다.

| 시작할 도구 | 사용하는 곳 |
| --- | --- |
| [터미널 작업 공간](./sessions) | 대화·초안·파일 문맥을 관리합니다. 미리보기를 사용할 수 있으며 연결 대화에는 아직 미구현인 로컬 게이트웨이가 필요합니다. |
| [공급처 도구](./connections) | 계정을 연결하고 모델을 조회하거나 직접 호출합니다. |
| [네이티브 패키지](./installation) | Node.js 없이 실행 파일을 설치하고 업데이트·롤백합니다. |

## 공급처 연결

~~~sh
freeway providers auth kilo
freeway providers models kilo
~~~

현재 모델 목록부터 확인하세요. API 키, 공식 로그인, 무료 계정 확인과 제한은 [공급처 연결](./connections)에 정리되어 있습니다.

## 대화 시작

<Aside title="로컬 게이트웨이가 필요합니다">
연결 모드는 인증된 로컬 Go 게이트웨이 API v1을 사용합니다. 이 체크아웃의 공통 게이트웨이는 현재 미구현이며 마지막 백엔드 단계에서 개발합니다. 지금은 오프라인 미리보기와 공급처 직접 호출 명령을 사용할 수 있습니다. 클라이언트는 기존 POC를 몰래 실행하거나 샘플 응답으로 대체하지 않습니다.
</Aside>

로컬 게이트웨이가 발급한 주소와 클라이언트 키를 설정합니다.

~~~sh
export FREEWAY_URL=http://127.0.0.1:4141
export FREEWAY_API_KEY=your-local-gateway-client-key
freeway
~~~

PowerShell에서는 `$env:FREEWAY_URL`, `$env:FREEWAY_API_KEY`를 사용합니다. 이 키는 업체 API 키와 다른 로컬 게이트웨이 키입니다. 이슈나 화면 캡처에 넣지 마세요.

`/model`에서 모델을 선택하고 질문을 입력한 뒤 **Enter**를 누릅니다. **Esc**로 응답을 중지해도 다음 초안은 유지됩니다.

## 작업 이어가기

~~~sh
freeway continue
freeway resume
freeway sessions
~~~

저장 목록은 현재 프로젝트 기준입니다. 첨부·분기·복원은 [대화와 초안](./sessions)을 참고하세요.
