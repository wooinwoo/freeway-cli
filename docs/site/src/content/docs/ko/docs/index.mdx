Freeway는 개인 PC에서 실행되는 Go 기반 터미널 클라이언트입니다. 본인의 계정으로 모델 API와 공식 CLI를 연결하고 대화·초안·파일 문맥을 함께 관리합니다.

## 네이티브 클라이언트 설치

공식 [GitHub Releases](https://github.com/wooinwoo/freeway-cli/releases)의 네이티브 패키지를 설치합니다. Go와 Node.js는 필요하지 않습니다.

<Tabs>
<TabItem label="Linux / macOS">

~~~sh
curl -fsSLO https://raw.githubusercontent.com/wooinwoo/freeway-cli/main/install.sh
bash install.sh
export PATH="$HOME/.freeway/app/bin:$PATH"
freeway --preview
~~~

</TabItem>
<TabItem label="Windows">

릴리스에서 **Freeway-Setup-x64.exe**(Windows on Arm은 **Freeway-Setup-arm64.exe**)를 받아 실행한 뒤 시작 메뉴에서 **Freeway**를 엽니다.

</TabItem>
</Tabs>

스크립트는 OS·CPU를 감지하고 최신 릴리스의 체크섬을 확인한 뒤 `freeway`, `freewayd`, `freeway-providers`를 함께 설치합니다. 소스 설치(Go 1.26 이상), 로컬 압축 파일, 설치 위치 지정은 [설치 안내](./installation)를 참고하세요. 미리보기는 계정 없이 오프라인으로 동작합니다.

## Freeway 둘러보기

필요한 기능부터 시작하세요. 모든 도구는 자신의 컴퓨터에서 본인의 계정으로 실행합니다.

| 시작할 도구 | 사용하는 곳 |
| --- | --- |
| [터미널 작업 공간](./sessions) | 로컬 게이트웨이에 연결해 대화·초안·파일 문맥을 관리합니다. |
| [공급처 도구](./connections) | 계정을 연결하고 모델을 조회하거나 직접 호출합니다. |
| [네이티브 패키지](./installation) | Node.js 없이 실행 파일을 설치하고 업데이트·롤백합니다. |

## 공급처에 직접 첫 요청 보내기

설치 후 함께 들어 있는 공급처 도구를 실행하세요. 자신의 PC에서 Kilo로 요청을 보내며 공급처 할당량을 사용합니다.

~~~sh
freeway providers auth kilo
freeway providers models kilo
freeway providers probe kilo --model MODEL_ID
~~~

`MODEL_ID`는 모델 목록에서 받은 ID로 바꾸세요. 진단 요청이 성공하면 `FREEWAY_PROVIDER_OK`가 반환됩니다. API 키와 공식 CLI 로그인, 무료 사용 조건은 [공급처 연결](./connections/)에서 확인하세요.

## 터미널 작업 공간 연결

`freeway`를 실행하면 [로컬 게이트웨이](./gateway/)가 자동으로 시작됩니다. `freeway continue`로 현재 프로젝트의 최근 대화를 이어갈 수 있습니다.

프로젝트별 세션과 첨부·복구는 [대화와 초안](./sessions/)에서 확인할 수 있습니다.
