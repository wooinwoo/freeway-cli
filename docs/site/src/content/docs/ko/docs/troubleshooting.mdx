## 게이트웨이 연결 실패

Freeway를 다시 열면 내장 게이트웨이에 다시 연결합니다. 직접 `FREEWAY_URL`을 지정했다면 루프백 주소와 `FREEWAY_API_KEY`를 확인하세요. `freeway --preview`로 화면을 오프라인에서 열 수 있습니다.

## 로그인 또는 키 필요

`FREEWAY_API_KEY`는 로컬 연결을, 공급처 키는 각 서비스를 인증합니다. OpenCode·Cline은 공식 로그인을 사용합니다. 이슈에 키를 붙여 넣지 마세요.

`credential_conflict`는 다른 명령이 같은 공급처를 변경했다는 뜻입니다. 현재 계정을 확인한 뒤 다시 확인하세요.

## 준비된 무료 모델 없음

현재 모델 목록과 `freeway providers quota all`을 확인하세요. 설정·목록 존재·실제 응답 성공은 다릅니다. 프로모션 종료나 계정 한도 도달일 수 있습니다.

## 응답 중단·불완전한 응답

부분 답변은 미완료로 보존하고 이후 모델 문맥에서 제외합니다. 가용성을 확인하고 Alt+R로 재시도하세요. 출력이 시작된 뒤 모델을 몰래 전환하지 않습니다.

## 다른 창에서 변경된 대화

이 창의 작업을 내보내고 저장 대화를 다시 여세요. revision 충돌은 최신 저장본을 보호합니다.

## 저장 실패

`/save`로 재시도하거나 `/export backup.md`로 첨부·미완성 작업을 평문으로 남기세요. 게이트웨이 저장 권한과 디스크 여유를 확인하세요.

## 문제 제보

네이티브 버전·OS·공급처 ID·명령·짧은 재현 절차를 포함하세요. 키·개인 프롬프트·파일 경로는 제거하고 [GitHub 이슈](https://github.com/wooinwoo/freeway-cli/issues)를 사용하세요.
