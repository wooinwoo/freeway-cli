## 게이트웨이 연결 실패

대화 중 `/reconnect`로 내장 게이트웨이를 다시 찾을 수 있습니다. 직접 `FREEWAY_URL`을 지정했다면 루프백 주소와 `FREEWAY_API_KEY`를 확인하세요. `freeway --preview`로 화면을 오프라인에서 열 수 있습니다.

## 로그인 또는 키 필요

`FREEWAY_API_KEY`는 로컬 연결을, 공급처 키는 각 서비스를 인증합니다. OpenCode·Cline은 공식 로그인을 사용합니다. 이슈에 키를 붙여 넣지 마세요.

`credential_conflict`는 다른 명령이 같은 공급처를 변경했다는 뜻입니다. 현재 계정을 확인한 뒤 다시 확인하세요.

## 준비된 무료 모델 없음

현재 모델 목록과 `freeway providers quota all`을 확인하세요. 설정·목록 존재·실제 응답 성공은 다릅니다. 프로모션 종료나 계정 한도 도달일 수 있습니다.

## 응답 중단·불완전한 응답

부분 답변은 미완료로 보존하고 이후 모델 문맥에서 제외합니다. **Alt+R**로 선택한 모델을 재시도할 수 있습니다. 다른 무료 모델로 보내려면 `/auto`로 전환한 뒤 **Alt+R**을 누르세요.

## 다른 창에서 변경된 대화

저장된 대화를 다시 열고 **F6**으로 이 창에 남은 작업을 복구 파일에 보존하세요. 저장 충돌 시 다른 창의 저장본을 유지합니다.

## 저장 실패

일시적 오류는 `/save`로 재시도하세요. 저장 한도를 넘겼다면 **F6**으로 첨부와 초안이 포함된 평문 복구 파일을 남길 수 있습니다. 기록에 `Conversation needs recovery`가 보이면 해당 원본 파일을 보존하고 백업에서 복원하세요.

## 문제 제보

네이티브 버전·OS·공급처 ID·명령·짧은 재현 절차를 포함하세요. 키·개인 프롬프트·파일 경로는 제거하고 [GitHub 이슈](https://github.com/wooinwoo/freeway-cli/issues)를 사용하세요.
