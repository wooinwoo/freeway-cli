## 모델 선택

`/model`, **F2**, **Alt+P**로 목록을 엽니다. 검색하고 선택한 뒤 이어서 입력합니다. 메뉴를 닫아도 초안은 유지됩니다.

게이트웨이가 무료이면서 준비되었다고 명시한 모델을 표시합니다. 같은 모델을 제공하는 공급처가 여러 곳이면 한 항목에 공급처를 함께 표시합니다. 응답에 실제로 사용한 모델과 공급처가 표시됩니다.

목록에서 **Ctrl+T**로 종합·코딩·추론 순위를 전환합니다. 코딩은 Terminal-Bench 4.0, 추론은 HLE-Diamond를 참고합니다. 해당 비교 자료가 있는 모델끼리 순서를 바꾸고 다른 모델은 종합 순서의 위치를 유지합니다. 비교는 2026-11-20에 확인한 모델 버전을 기준으로 합니다. 실제 무료 경로의 추론 설정과 결과는 평가 조건과 다를 수 있습니다. [Terminal-Bench 4.0](https://artificialanalysis.ai/evaluations/terminalbench-4-0) · [HLE-Diamond](https://artificialanalysis.ai/evaluations/hle-diamond)

**Auto**는 최근 질문에서 함수 구현, 코드 수정, 명제 증명 같은 요청을 감지하면 해당 순위를 사용합니다. 직접 고른 모델과 공급처 우선순위 설정은 그대로 적용됩니다.

응답을 기다리면서 모델이나 응답 길이를 바꿀 수 있습니다. 새 선택은 다음 질문부터 적용됩니다.

선택한 모델을 제공하는 경로가 모두 사라지면 모델 선택과 초안을 유지합니다. **F2**를 열고 **Ctrl+R**로 확인한 뒤 같은 모델로 질문을 보낼 수 있습니다. 일시정지된 후속 질문은 `/queue resume`으로 이어서 보냅니다.

## 입력과 스트리밍

**Enter**는 전송입니다. **Ctrl+J**, **Ctrl+O**, **Alt+Enter**, **Shift+Enter**는 줄바꿈입니다. 입력창은 최대 여섯 줄까지 늘어납니다.

응답 중 다음 질문을 쓰고 **Tab** 또는 **Enter**로 대기열에 넣습니다. `/queue pause`, `resume`, `clear`로 제어합니다. 복원한 대기열은 일시 정지 상태입니다.

## 중지와 재시도

현재 질문과 문맥을 포함해 로컬 한도를 넘을 것으로 보이면 입력창에 예상 응답 길이가 표시됩니다. 게이트웨이가 더 짧은 응답 길이를 제안하면 **F5**로 한 번 재시도할 수 있습니다. 기본 응답 길이는 `/settings`에서 조정합니다.

**Esc**로 다음 초안을 유지하며 응답을 중지합니다. **Alt+R**은 마지막 질문을 재생성합니다. 대화 로딩 중에는 재생성을 시작하지 않습니다.

## 전송할 문맥 확인

**F8** 또는 `/context`는 다음 초안에 포함되는 이전 질문과 첨부를 보여줍니다. 이전 대화 범위에서는 Enter로 전체, 최근 8개, 최근 3개, 현재 질문만 포함 중에서 고릅니다. `/context last 2`처럼 원하는 개수도 지정할 수 있습니다.

**F8**에서 파일을 선택하고 Enter를 누르면 같은 경로의 이전 첨부를 제외하거나 다시 포함합니다. **Clear file exclusions**로 개별 제외를 모두 해제할 수 있습니다. 이전 첨부 항목 또는 `/context attachments off`는 개별 설정을 유지한 채 이전 첨부 전체를 끕니다.

현재 질문의 첨부는 포함됩니다. Alt+R과 F5로 질문을 재시도할 때는 그 질문의 첨부도 함께 전송합니다. 설정은 대화별로 저장되며 원본 메시지와 첨부는 기록에서 열 수 있습니다.

응답이 시작되기 전에 공급처가 한도에 걸리거나 연결에 실패하면 게이트웨이가 같은 모델의 다른 공급처를 시도합니다. 출력이 시작된 뒤에는 부분 응답과 오류를 보존합니다. 실패·중지한 AI 메시지는 이후 모델 문맥에서 제외합니다.

## 사용량 이해

사용량 미제공은 확인된 0이 아닙니다. quota 화면은 설정과 관측 오류를 보여주며 정확한 잔여량을 보장하지 않습니다. 다른 앱이 같은 한도를 사용할 수 있고 무료 프로모션도 종료될 수 있습니다.
