## 모델 선택

`/model`, **F2**, **Alt+P**로 목록을 엽니다. 검색하고 선택한 뒤 이어서 입력합니다. 메뉴를 닫아도 초안은 유지됩니다.

게이트웨이가 무료이면서 준비되었다고 명시한 모델만 표시합니다. 자동 선택은 게이트웨이의 정책이며 응답에는 실제 모델을 표시합니다.

## 입력과 스트리밍

**Enter**는 전송입니다. **Ctrl+J**, **Ctrl+O**, **Alt+Enter**, **Shift+Enter**는 줄바꿈입니다. 입력창은 최대 여섯 줄까지 늘어납니다.

응답 중 다음 질문을 쓰고 **Tab** 또는 **Enter**로 대기열에 넣습니다. `/queue pause`, `resume`, `clear`로 제어합니다. 복원한 대기열은 일시 정지 상태입니다.

## 중지와 재시도

**Esc**로 다음 초안을 유지하며 응답을 중지합니다. **Alt+R**은 마지막 질문을 재생성합니다. 대화 로딩 중에는 재생성을 시작하지 않습니다.

선택한 경로가 출력 전에 실패하면 Auto로 다시 시도하고 화면에 알립니다. 출력이 시작된 뒤에는 부분 응답과 오류를 보존합니다. 실패·중지한 AI 메시지는 이후 모델 문맥에서 제외합니다.

## 사용량 이해

사용량 미제공은 확인된 0이 아닙니다. quota 화면은 설정과 관측 오류를 보여주며 정확한 잔여량을 보장하지 않습니다. 다른 앱이 같은 한도를 사용할 수 있고 무료 프로모션도 종료될 수 있습니다.
