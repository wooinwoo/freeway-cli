## 명령

`/model`, `/resume`, `/continue`, `/new`, `/fork`, `/rename`, `/attach`, `/detach`, `/queue`, `/save`, `/export`, `/copy`, `/code`, `/settings`, `/reconnect`를 사용합니다.

`/`를 입력하면 명령을 제안합니다. 화살표로 고르고 Tab으로 완성합니다. 메뉴가 열려 있으면 Esc는 메뉴부터 닫습니다.

## 안전하게 종료

Ctrl+C는 생성 중에는 중지합니다. 입력이 있으면 복원 가능한 사본을 유지하며 입력창을 비웁니다. 빈 입력에서 두 번 누르면 종료합니다. `/exit`는 저장 후 종료를 요청합니다.
