## Windows에서 바로 설치

공식 [GitHub Releases](https://github.com/wooinwoo/freeway-cli/releases)에서 Windows 설치 파일을 받습니다. 대부분의 Windows PC는 **Freeway-Setup-x64.exe**, Windows on Arm은 **Freeway-Setup-arm64.exe**를 사용합니다.

1. 파일을 더블클릭한 뒤 설치를 확인합니다.
2. 완료 화면에서 Freeway를 엽니다. 이후에는 시작 메뉴에서 **Freeway**를 검색하면 됩니다.

설치 파일에 전체 패키지가 포함됩니다. 관리자 권한, Go, Node.js, PATH 설정이 필요하지 않습니다. 서명되지 않은 설치 파일에는 Windows가 확인 화면을 표시할 수 있습니다. 설치 위치는 `$HOME\.freeway\app`입니다.

패키지에는 `freeway`, `freewayd`, `freeway-providers`, 파일 검증 명세와 라이선스가 들어 있습니다. 운영체제와 CPU에 맞는 패키지를 선택하고 세 실행 파일을 함께 보관하세요. `freewayd`가 로컬 게이트웨이를 실행합니다.

## Linux·macOS 설치

설치 스크립트를 받아 옵션 없이 실행합니다. OS·CPU를 감지하고 최신 릴리스의 `SHA256SUMS`와 해당 압축 파일을 받아 검증한 뒤 설치하므로 Go·Node.js가 필요하지 않습니다. `curl`, `tar`, `sha256sum` 또는 `shasum`이 필요합니다.

~~~sh
curl -fsSLO https://raw.githubusercontent.com/wooinwoo/freeway-cli/main/install.sh
bash install.sh
export PATH="$HOME/.freeway/app/bin:$PATH"
~~~

Windows에서 스크립트를 쓰려면 같은 방식으로 `install.ps1`을 받아 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`을 실행합니다. 릴리스를 받을 수 없으면 기존 설치를 바꾸지 않고 실패합니다. `--release-url HTTPS_BASE_URL` / `-ReleaseUrl HTTPS_BASE_URL`은 신뢰하는 릴리스 폴더를 지정합니다. `--root PATH` / `-Root PATH`로 전용 설치 폴더를 지정합니다. 위 PATH 설정은 현재 터미널에 적용됩니다. 이후 터미널에서도 사용하려면 셸 설정이나 Windows 사용자 PATH에 같은 폴더를 추가하세요.

<Aside title="공식 출처만 사용">
릴리스는 공식 GitHub Releases에서만 받으세요. 각 릴리스에는 OS·CPU별 압축 파일, Windows 설치 파일 2종, `SHA256SUMS`, `release.json`과 서명 `release.json.sig`가 있습니다. 출처가 다른 미러에서 파일을 내려받지 마세요.
</Aside>

## 소스에서 설치

Go 1.26 이상과 저장소 체크아웃이 필요합니다.

<Tabs>
<TabItem label="Linux / macOS">

~~~sh
bash install.sh --source
export PATH="$HOME/.freeway/app/bin:$PATH"
~~~

</TabItem>
<TabItem label="Windows">

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Source
$env:Path = "$HOME\.freeway\app\bin;$env:Path"
~~~

</TabItem>
</Tabs>

현재 OS·CPU용 패키지를 빌드하고 검증한 뒤 네이티브 설치기에 활성화를 맡깁니다. Node.js는 사용하지 않습니다.

## 로컬 압축 파일 설치

압축을 직접 풀 필요가 없습니다.

~~~sh
bash install.sh --archive ./freeway_VERSION_linux_amd64.tar.gz --sha256 EXPECTED_SHA256
~~~

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -Archive .\freeway_VERSION_windows_amd64.zip -SHA256 EXPECTED_SHA256
~~~

신뢰하는 출처의 체크섬을 사용하세요. 압축 파일을 검증한 뒤에만 실행 파일을 사용합니다.

## 배포 압축 파일 빌드

Go 1.26 이상을 설치하고 저장소 루트에서 실행합니다.

~~~sh
go -C cli run ./cmd/package --root "$PWD"
~~~

`dist/native`에 Linux·macOS·Windows의 amd64·arm64 압축 파일, Windows Setup EXE 2종, `SHA256SUMS`, `release.json`이 생성됩니다. 한 대상만 빌드하려면 `--targets linux/amd64`를 추가하세요. 교차 빌드와 각 운영체제의 실행 검증은 별도 단계입니다.

## 검증 후 설치

신뢰하는 릴리스의 `SHA256SUMS`에서 예상 SHA256을 확인하세요. 예상 해시의 출처도 신뢰할 수 있어야 변조 여부를 판단할 수 있습니다.

<Tabs>
<TabItem label="macOS / Linux">

~~~sh
# 파일명에 실제 버전과 아키텍처를 사용합니다.
sha256sum freeway_VERSION_linux_amd64.tar.gz
# macOS: shasum -a 256 freeway_VERSION_darwin_arm64.tar.gz
mkdir freeway-package
tar -xzf freeway_VERSION_linux_amd64.tar.gz -C freeway-package
./freeway-package/freeway install \
  --archive ./freeway_VERSION_linux_amd64.tar.gz \
  --sha256 EXPECTED_SHA256
~~~

`$HOME/.freeway/app/bin`을 셸의 PATH에 추가하고 새 터미널을 여세요.

</TabItem>
<TabItem label="Windows">

~~~powershell
Get-FileHash .\freeway_VERSION_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\freeway_VERSION_windows_amd64.zip .\freeway-package
.\freeway-package\freeway.exe install --archive .\freeway_VERSION_windows_amd64.zip --sha256 EXPECTED_SHA256
~~~

사용자 PATH에 `$HOME\.freeway\app\bin`을 추가하고 새 터미널을 여세요. 서명되지 않은 실행 파일에 대해 Windows가 확인을 요청할 수 있습니다. 관리자 설치는 필요하지 않습니다.

</TabItem>
</Tabs>

`VERSION`과 `EXPECTED_SHA256`은 실제 파일명과 해시로 바꾸세요. 압축을 푼 실행 파일을 처음 실행하기 전에 해시부터 검증하세요. `--root PATH`로 전용 설치 폴더를 지정할 수 있습니다. 이때 해당 폴더의 `bin`을 PATH에 추가합니다.

## 설치 확인

~~~sh
freeway --version
freeway
~~~

Freeway가 내장 게이트웨이를 시작하고 대화 화면을 엽니다. 화면만 오프라인으로 확인할 때는 `freeway --preview`를 사용하세요. [게이트웨이 옵션](./gateway/)

## 설치 구조

~~~text
~/.freeway/app/
  bin/freeway                 고정 실행 진입점 (Windows는 freeway.exe)
  install.json                활성 버전과 이전 버전
  versions/VERSION/
    freeway
    freewayd
    freeway-providers
    manifest.json
    LICENSE
    THIRD_PARTY_NOTICES.md
    licenses/
~~~

공급처 계정과 게이트웨이 대화 데이터는 프로그램 폴더 밖에서 관리합니다. `versions` 안에 개인 파일을 보관하지 마세요.
