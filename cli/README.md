# CLI·TUI

사용자 명령, 로컬 백엔드 연결, 터미널 화면을 구현할 영역입니다. 구현 언어와 빌드 도구는 아직 정하지 않았습니다.

- `commands/`: 연결·모델·우선순위·사용량·설정 명령과 백엔드 시작 흐름.
- `client/`: 로컬 API 인증·요청·스트리밍·취소.
- `tui/`: 터미널 화면과 상태 표시.

백엔드의 `internal/` 패키지나 상태 파일을 직접 사용하지 않습니다. 통신 계약은 [`api/openapi.yaml`](../api/openapi.yaml), 전체 책임은 [구조 문서](../docs/development/architecture.md)를 따릅니다. 현재 API 파일은 빈 계약 틀이므로 사용할 엔드포인트는 없습니다.
