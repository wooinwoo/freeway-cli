# CLI·TUI

Go와 Bubble Tea로 만든 영어 UI의 TUI 미리보기입니다. Nekot의 모델 목록·입력창·Groovebox 색상을 추려 사용합니다. 출처와 라이선스는 [제3자 고지](../THIRD_PARTY_NOTICES.md)를 참고하세요.

```bash
go -C cli run ./cmd/freeway
```

대화는 테두리 없이 표시하고 입력창은 하단에 고정합니다. 입력창은 1줄에서 시작해 여러 줄 입력과 자동 줄바꿈에 따라 최대 6줄까지 늘어납니다. 더 긴 초안은 입력창 안에서 스크롤하며, 작은 창에서는 표시 높이만 줄입니다.

- `Enter`: 입력을 화면에 추가.
- `Ctrl+J` 또는 `Alt+Enter`: 줄바꿈.
- `/`: `/model` 명령 제안 표시. `Tab`으로 완성하고 `Enter`로 실행.
- `/model`: 모델 메뉴 열기. 기존 `/models`도 호환합니다.
- `Ctrl+P` 또는 입력이 명령 제안 상태가 아닐 때 `Tab`: 모델 메뉴 열기.
- 모델 메뉴의 `↑/↓`: 이동, `/`: 검색, `Enter`: 검색 확정 또는 모델 선택, `Esc`: 닫기.
- `PgUp/PgDn` 또는 마우스 휠: 대화 스크롤.
- `Ctrl+C`: 종료.

모델 목록은 메뉴를 열 때만 표시합니다. 메뉴를 닫거나 모델을 선택해도 작성 중인 초안은 유지합니다. 최소 창 크기는 44×12입니다.

모델은 `preview/*` 샘플입니다. 입력은 메모리에만 남고 종료하면 사라집니다. API 호출, 인증정보 읽기, DB, 웹 검색, 자동 제목 생성, 파일 첨부는 포함하지 않습니다. 백엔드 연결이나 실제 응답 생성은 구현하지 않았습니다.

- `cmd/freeway/`: Go 실행 진입점.
- `commands/`: 연결·모델·우선순위·사용량·설정 명령과 백엔드 시작 흐름.
- `client/`: 로컬 API 인증·요청·스트리밍·취소.
- `tui/`: 화면 상태·입력창·모델 목록·스타일과 원본 MIT 고지.

`commands/`와 `client/`는 빈 개발 영역입니다. 백엔드의 `internal/` 패키지나 상태 파일을 직접 사용하지 않습니다. 통신 계약은 [`api/openapi.yaml`](../api/openapi.yaml), 전체 책임은 [구조 문서](../docs/development/architecture.md)를 따릅니다. 현재 API 파일은 빈 계약 틀입니다.
